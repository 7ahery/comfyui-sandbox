# Every question is also a flag; a missing answer exits 9

The CLI is interactive by default, with computed defaults, and every question can also be answered with a flag. `--yes` accepts the defaults; `--non-interactive` never prompts. Questions that only come up during preflight (port taken, distro name taken, other distros running when `wsl --shutdown` is needed) are prompted in a terminal. When the CLI can't ask, it exits 9 with a plain message: what is wrong, the options, and the flag that answers it (for example "Port 8188 is used by python.exe (PID 4120). Re-run with `--port <n>`; 8189 is free."). Under `--json` the flag is also in the `flag` key. A caller reads the message, asks the user, and reruns with the named flag, so the same plain message serves scripts and people.
